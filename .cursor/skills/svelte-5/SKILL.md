# Svelte 5

This repo is Svelte 5 + SvelteKit. Vite forces runes outside `node_modules`.

## Use

- Props: `let { foo }: { foo: string } = $props()`
- State: `$state`, `$derived`, `$effect`
- Events: `onclick`, `onmousemove` (not `on:click`)
- Children: snippets / `{@render children()}`, not `<slot>`
- Motion: `svelte/transition`, `svelte/animate`

## Do not

- `export let`
- `$: ` reactive statements
- `createEventDispatcher`
- `on:click` / `on:mousemove` directives
- `<slot>` instead of snippets
- Svelte 4 stores just to avoid runes

## Kit

- `+page.svelte` / `+page.ts` / `+layout.svelte` as generated by current `sv create`.
- Tailwind v4: `@import 'tailwindcss'` + `@tailwindcss/vite`. No `tailwind.config.js` unless you must.
- `pnpm check` before you call it done.
