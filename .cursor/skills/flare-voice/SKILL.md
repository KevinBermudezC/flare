# Flare voice

Flare is a **Svelte 5 gallery of marketing and motion blocks**. Live preview. Copy the `.svelte`. It's yours.

## Do

- Name the product **Flare**.
- Own look: ink, ember, spotlight, beams, console chrome. That look is Flare's, not a borrowed identity.
- Say what it is not: design system, Tangram, npm kit, CLI/registry, shared `Button`.

## Do not

- Describe Flare as a clone, port, or “X-style” / “X for Svelte”.
- Compare Flare to other galleries in README, UI, comments, commits, or OpenSpec.
- Treat dark ink as a theme-toggle feature.

## Surfaces

README, `package.json` description, `<meta name="description">`, home intro, block comments, OpenSpec artifacts, commit messages, PR text. All of the above.

## Visual work

Pixels follow [design-taste-frontend](../design-taste-frontend/SKILL.md). Redesigns of existing surfaces start with [redesign-existing](../redesign-existing/SKILL.md). Taste does not excuse clone framing.
