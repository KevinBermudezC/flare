# Agents

Read these skills before non-trivial work. They are the contract, not optional flavor.

| Skill | When |
| --- | --- |
| [Spec-driven development](.cursor/skills/spec-driven-development/SKILL.md) | Any non-trivial change |
| [Flare blocks](.cursor/skills/flare-blocks/SKILL.md) | Adding or editing a block under `src/blocks/` |
| [Flare voice](.cursor/skills/flare-voice/SKILL.md) | README, UI copy, OpenSpec, comments, commits, PR text |
| [Svelte 5](.cursor/skills/svelte-5/SKILL.md) | Any `.svelte` / SvelteKit file |

OpenSpec CLI helpers live under `.cursor/skills/openspec-*` and `.cursor/commands/opsx-*`. Use those for `/opsx:propose` → `/opsx:apply` → `/opsx:archive`. Do not add more skills unless Kevin asks.
